# Open Source Chess Puzzle Generation

This repository provides tools to generate and evaluate chess puzzles using a pre-trained masked diffusion model (`MaskedDiffusion`).

## Requirements
* **Stockfish**: Ensure the Stockfish binary is installed (e.g., at `./Stockfish/src/stockfish` or configured path).

## Setup
* Install backend dependencies: `uv sync`
* Install frontend dependencies: `cd frontend && npm ci`
* Run the backend: `uv run src/mock_server.py`
* Run the frontend: `cd frontend && npm run dev`
---

## Core Generation Pipeline

The generation pipeline works as follows:
1. **Sample Candidates**: Use the diffusion model to generate `n` candidate chess positions for target themes and rating.
2. **Evaluate in Parallel**: Analyze candidate positions with a pool of Stockfish engines to verify legality, uniqueness, and themes.
3. **Select / Filter**: Select the top-quality evaluations.

---

## Core API Reference

The primary developer functions are located in the `ChessGeneration` package.

### 1. `generate`
Generates a list of candidate `Position` objects using the pre-trained diffusion model.

```python
from ChessGeneration import generate, MaskedDiffusion


checkpoint = torch.load(Path("models/model.pt"), map_location="cpu", weights_only=False)
config = checkpoint["config"]
model = MaskedDiffusion(config)
model.load_state_dict(checkpoint["model"])
model.to(device=device)
model.eval()

positions = generate(
    themes=["fork", "pin"],
    rating=1500.0,
    model=model,
    n_attempts=256,
    steps=16
)
```

* **Parameters**:
  * `themes` (`list[str]`): List of target tactical themes (e.g., `["fork", "pin"]`). Complete list at `ChessGeneration.tokenization.unique_themes`.
  * `rating` (`float`): Target rating/difficulty for the generated positions.
  * `model` (`MaskedDiffusion`): Pre-trained model instance.
  * `n_attempts` (`int`, default: `256`): Number of candidate positions to generate.
  * `steps` (`int`, default: `16`): The number of diffusion sampling steps.
* **Returns**: `list[Position]`.

---

### 2. `evaluate_positions`
Runs multiple Stockfish processes in parallel to analyze candidate positions.

```python
from ChessGeneration import evaluate_positions

evaluations = evaluate_positions(
    positions=positions,
    n_jobs=4,
    stockfish_path=Path("./Stockfish/src/stockfish")
)
```

* **Parameters**:
  * `positions` (`list[Position]`): Candidate positions to evaluate.
  * `n_jobs` (`int`, default: `1`): Number of concurrent worker threads (and separate Stockfish instances) to run.
  * `stockfish_path` (`Path`, default: `./Stockfish/src/stockfish`): Path to the Stockfish executable.
* **Returns**: `list[Evaluation]` matching the indices of the input `positions`.

---

### 3. `choose_best_evaluations`
Filters and ranks evaluations to pick the best `n` candidates.

```python
from ChessGeneration import choose_best_evaluations

best_evals = choose_best_evaluations(evaluations, n=3)
```

* **Selection Priority**:
  1. **Legality** (`legal` must be `True`)
  2. **Uniqueness** (`unique_solution` must be `True`)
  3. **Theme Match** (`themes_match` must be `True`)
  4. **Counter-Intuitive Value** (`counter_intuitive_value` descending)
* **Parameters**:
  * `evaluations` (`list[Evaluation]`): Unfiltered evaluations.
  * `n` (`int`, default: `3`): Number of top-ranked evaluations to return.
* **Returns**: `list[Evaluation]` sorted by puzzle quality.

---

### 4. `is_evaluation_good_enough`
Determines if an evaluation is good enough to return to the user. Should be used to determine if we need to sample more positions or if we can return the best found to the user (perhaps initially attempt to find a position that passes the strictest requirements. If no such position is found, loosen the requirements and try again).

```python
from ChessGeneration import is_evaluation_good_enough, EvaluationFlag

is_good = is_evaluation_good_enough(
    evaluation=evaluation,
    flag=EvaluationFlag.UNIQUE_AND_THEMES
)
```

* **Acceptance Flags (`EvaluationFlag`)**:
  * `UNIQUE_SOLUTION`: Accepts if the position has a unique solution.
  * `UNIQUE_AND_THEMES`: Accepts if the solution is unique and verified themes match the target themes.
  * `UNIQUE_AND_THEMES_AND_COUNTER_INTUITIVE`: Accepts if unique, themes match, and the solution is counter-intuitive.
* **Returns**: `bool` (indicating whether the evaluation is accepted).

## Dataclasses

### `Position`
Represents a raw position candidate generated by the model.
* `fen` (`str`): FEN representation of the board state.
* `move` (`str | None`): The initial move proposed for the puzzle.
* `base_rating` (`float`): The requested rating used during generation.
* `base_themes` (`list[str]`): The requested themes used during generation.

### `Evaluation`
Encapsulates chess metrics verified by Stockfish analysis. This information should be transferred between the frontend and the backend.
* `position` (`Position`): The source position candidate.
* `legal` (`bool`): Whether the board layout is legal.
* `unique_solution` (`bool`): Whether the position has exactly one puzzle solution line.
* `counter_intuitive_solution` (`bool`): Whether the solution move sequence contains counter-intuitive elements.
* `counter_intuitive_value` (`float`): Score indicating how counter-intuitive the solution is.
* `themes_match` (`bool`): Whether Stockfish-verified tactical themes match the requested `base_themes`.
* `main_line` (`list[str]`): The solution moves for the puzzle. Empty list if the themes are not computed.
